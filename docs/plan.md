# Equestria atelier collection plan

Build nine original stylized figurines: Twilight Sparkle as an alicorn, Applejack, Rainbow Dash, Pinkie Pie, Fluttershy, Rarity, Princess Celestia, Princess Luna, and the user's original character Clockwork Relativity. Clockwork is Luna's son, a unicorn with a gold hourglass mark, as confirmed by the user. Use a shared sculptural language with character-specific hair, symbols, accessories, and royal proportions.

1. Establish a geometry contract, local Python toolchain, and procedural modeling source.
2. Build the character designs while independent workers implement CAD export and studio rendering.
3. Export named color STEP assemblies, boolean-unioned printable STL, and color GLB.
4. Inspect actual geometry renders and refine silhouettes and details.
5. Validate STEP import, positive-volume solids, mesh closure, winding, connectedness, scale, and archive contents.
6. Deliver a complete ZIP, an illustrated collection sheet, individual views, dimensional views, editing instructions, and measured verification results. Physical print tests are outside this session.
